In the notch

How it is built

A native SwiftUI and AppKit panel around the camera cutout. It reads what macOS reports as now playing, and for web media it names the site instead, read from the browser's tabs. The open notch pages between Music, Calendar, Timer and the shelf with a two-finger swipe.

The calendar page lists today's remaining events with a Join button for video calls, and the closed notch counts down to the next one. The panel stays out of screenshots and recordings by default.

Media takes one path: the player reports to macOS now playing, Eclipse reads that, and draws it in the notch. Dictation takes another: Sotto sends the microphone level over a local socket, and Eclipse draws the pill.

There is no plugin framework. Sotto reaches the notch only through that socket. The one external package, MediaRemoteAdapter, is pinned to a commit. The repository holds 1,054 focused checks for geometry, state, settings, hover, swipe, shelf, indicators, calendar, timer and dictation.
